➕ Website task entry

শুধু লিখিত অনুমতিপ্রাপ্ত course scope-এর hostname লিখুন। সফল ও ব্যর্থ দুই ফলই নথিভুক্ত করুন। URL path, credentials, payload বা exploit details প্রকাশ করবেন না।

📖 নির্দেশনা

  1. Course lead থেকে assigned domain, website এবং লিখিত অনুমতি নিশ্চিত করুন।
  2. নতুন Entry-তে domain ও website-এর শুধু hostname, task, চেষ্টা, ফলাফল, তারিখ এবং নিরাপদ সারাংশ লিখুন। ব্যর্থ হলেও entry দিন।
  3. Lead-এর দেওয়া submission key দিয়ে submit করুন; dashboard ও GitHub-এর domains/[domain]/findings.csv দেখুন।
  4. GitHub contributor হলে একই CSV ফাইলে সরাসরি edit বা pull request-ও করতে পারেন।

Real credentials, secret, URL path, payload ও exploit instructions public CSV-তে লিখবেন না।

❓ FAQ

Data কোথায় থাকে?

প্রতিটি assigned domain-এর জন্য GitHub-এর domains/example.org/findings.csv ফাইলে; website hostname-গুলো সেই CSV-তে row হিসেবে থাকে। আগের country lab data আলাদা ফাইলে সংরক্ষিত।

ব্যর্থ চেষ্টা রাখা যাবে?

হ্যাঁ। Attempted “হ্যাঁ”, Outcome “ব্যর্থ” নির্বাচন করুন এবং নিরাপদ সারাংশ লিখুন।

ভুল entry সংশোধন?

GitHub contributor হিসেবে সংশ্লিষ্ট CSV edit করে commit বা pull request দিন।

🐙 GitHub গাইড

Repository-র CONTRIBUTING.md অনুযায়ী browser edit বা branch + pull request দিয়ে contribution করুন। Site form submission key ছাড়া GitHub contributor access দেওয়া যায়।
